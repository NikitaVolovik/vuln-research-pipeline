# Disclosure Policy

## What I test

I only test open source software that I can install and run locally. Everything runs inside my own lab. I don't touch production systems, live websites or anyone else's infrastructure.

## How I report

1. I reproduce the issue in the lab and confirm it's real.
2. I report it privately through Patchstack, which handles contact with the vendor. For projects outside WordPress, I use the maintainer's security policy or a GitHub security advisory.
3. They get up to 90 days to fix it. If they're actively working on it and need more time, that's fine.
4. The CVE is assigned by Patchstack as a CNA, or through GitHub or MITRE for other projects.
5. The finding is added to [cves/](cves/) once there's a fix or the deadline has passed.
